# BlockBlast
Using knowledge from ECE 319H at UT Austin (Intro to Embedded Systems) to build a custom video game console and to program Block Blast from scratch. 

Block Blast is a fun and addictive puzzle game where players strategically place colorful block pieces on a grid to create complete rows or columns. Once completed, the rows or columns disappear, earning points and freeing up space for new blocks. The game features simple mechanics, vibrant visuals, and increasingly challenging levels, making it suitable for players of all ages.
